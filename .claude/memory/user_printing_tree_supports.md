Kyle always slices with tree supports on ("rather waste material than get a shit print and have to redo"). Material is PLA+ by default.

Implication for Spark CAD work (e.g. TendWright brackets, [[project_tendwright]]): overhangs are fine — design for structural/functional correctness first; don't trade design quality for support-free printability. Do still mention orientation/support expectations when delivering STLs.
